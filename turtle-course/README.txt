ЧЕРЕПАХА-ДОСЛІДНИК — 6 місій Python Turtle, 6–8 класи

ПУБЛІКАЦІЯ НА GITHUB PAGES
Завантажте папку turtle-course з архіву в корінь свого репозиторію.
Курс відкривається через turtle-course/index.html.
Головну сторінку ClassLus і її style.css замінювати не потрібно.
Або завантажте вміст папки в окремий репозиторій і ввімкніть GitHub Pages.

РОБОТА
У кожній місії: пояснення → складання алгоритму → код → питання → щоденник.
Перетягування має альтернативу кнопками ↑ і ↓.
Runner міститься всередині курсу й не залежить від раннера криптографічного сайту.
Skulpt і його стандартна бібліотека включені в assets; мережеві CDN не потрібні.
Runner показує результат без анімації. Дію speed() досліджуйте в ЄPython:
https://samel.ho.ua/
Копіюйте код або завантажуйте .py. Нові приклади в ЄPython потребують перевірки викладачем.

ЗВІТ
HTML-звіт містить код, відповіді та висновки. PDF: «Звіт для друку / PDF» → збереження як PDF.
Останній малюнок додається після успішного запуску, якщо браузер дозволяє експорт полотна.
Самооцінка та виконання без помилок не означають автоматичну оцінку правильності проєкту.
Прогрес зберігається на цьому пристрої в цьому браузері. Автоматичного надсилання вчителю немає.
