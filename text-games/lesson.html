Лабораторія гри

Спочатку перегляньте приклад. У полі «Відповіді» кожен новий рядок — відповідь на наступний input(). Змініть їх, щоб пройти інший маршрут.

Python завантажиться після натискання «Запустити».

Якщо виникла помилка
SyntaxError — перевірте лапки й двокрапки. IndentationError — перевірте відступи. ValueError — для числа введіть цифри, для float використовуйте крапку. EOFError — додайте відповіді для всіх input(). Нескінченний цикл можна зупинити кнопкою «Зупинити».
Змініть гру
Мій чекліст
Позначки — ваша самооцінка. Запуск коду сам по собі не підтверджує виконання завдання.
Перевірте розуміння
ШІ як помічник
Спробуйте запит: «Ось мій код і текст помилки. Не переписуй гру повністю. Поясни причину й дай одну підказку». Після виправлення поясніть, що саме змінилося.
