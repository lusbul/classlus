Які бувають СУБД

MySQL, MariaDB, PostgreSQL, Microsoft SQL Server, Oracle Database — приклади реляційних СУБД. MongoDB — документоорієнтована NoSQL-СУБД, Redis часто застосовують для структури «ключ — значення». SQL — мова запитів, а не назва СУБД.
