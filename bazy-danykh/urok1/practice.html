Практична робота

На першому знайомстві не потрібно створювати таблиці з нуля. Відкрийте готовий SQL-файл, ознайомтеся з його вмістом, спробуйте виконати команди в dat.A та дослідіть таблицю гравців. Якщо імпорт файлу не підтримується, скопіюйте SQL у редактор. Інтерфейс і доступні команди середовища можуть відрізнятися.

Готова база для дослідження

Це демонстраційні вигадані дані. SQL можна скопіювати в редактор dat.A; окремий файл також є в архіві.

CREATE TABLE players (id INTEGER PRIMARY KEY, nickname TEXT, coins INTEGER, level INTEGER);
INSERT INTO players VALUES (1,'Лис',180,3),(2,'Зірка',250,5),(3,'Комета',120,2);
SELECT * FROM players;
