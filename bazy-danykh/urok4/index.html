04 · ПОШУК І АНАЛІЗ

Кого шукає менеджер?

WHERE — знайдіть усіх Петренків.
AND — знайдіть лише Івана Петренка.
LIKE — знайдіть прізвища, які починаються на «К».
ORDER BY — відсортуйте співробітників за прізвищем.
Самостійно: замініть умову так, щоб знайти всі імена, які починаються на «Т». Спробуйте LIKE 'Т%'.
05 · ЗМІНИ В КОМАНДІ

INSERT, UPDATE, DELETE

У студії з’являються нові працівники, хтось змінює роль або залишає команду. SQL дозволяє керувати записами. Увага: без WHERE команди UPDATE і DELETE можуть змінити всі записи.

Новий працівник

INSERT INTO phone
(code, num, fam, name)
VALUES (200, '0500000000', 'Кірик', 'Оля');

Заміна контакту

UPDATE phone
SET fam='Мельник', name='Дарина'
WHERE num='0505721022';
Після кожної зміни виконайте SELECT * FROM phone;, щоб перевірити результат. Потрібно повернути вихідні дані? Натисніть «Відновити базу».
06 · ТРИ ТАБЛИЦІ

Як пов’язати дані?

phone.code → project.codeb

Код проєкту з таблиці контактів указує на проєкт.

project.codeb → payment.codes

Код проєкту пов’язує назву, бюджет і дедлайн.

За допомогою INNER JOIN менеджер бачить не окремі списки, а спільний звіт.

Завдання студії: дізнайтеся, над яким проєктом працює Коваленко Тетяна та яка сума зазначена для цього проєкту. Пам’ятайте: у прикладі payment.price — сума для проєкту, а не автоматично зарплата однієї людини.
