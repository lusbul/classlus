Роздоріжжя пригод

Умови if та else

🚦

🔎 Відкриття дня

Алгоритм із вибором виконує різні дії залежно від умови. if перевіряє умову, а else пропонує іншу дію. Після двокрапки команди всередині гілки пишуть із відступом.

Порівняння age >= 10 означає «вік не менший за 10». Результат перевірки — True або False.

📚 Як програма обирає смайлик під настрій?

Щодня ми робимо вибір: взяти парасольку чи ні, одягнути куртку чи футболку. Програма також може обирати дію за умовою. if перевіряє умову, else виконується, коли вона хибна.

🤖 ШІ — помічник, а не автор

Якщо код не працює, спочатку прочитай помилку. Потім можна попросити ШІ пояснити її простими словами, але не писати всю програму замість тебе.

«Я вивчаю Python. Поясни, що означає моя помилка, і дай одну підказку, не розв’язуючи завдання за мене. Ось код: …»

Не вводь у ШІ особисті дані, паролі й адреси.
