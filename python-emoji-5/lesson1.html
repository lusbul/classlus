Знайомся — Python

Python — мова програмування, якою люди створюють програми, ігри, сайти та системи штучного інтелекту. Її придумав Гвідо ван Россум. Він зробив чудову річ: створив мову, код якої легко читати навіть початківцям!

Дізнатися більше: історія Python

Гвідо ван Россум почав працювати над Python наприкінці 1989 року, а першу публічну версію випустив у 1991 році. Назва походить від британського комедійного шоу Monty Python, а не від назви змії.

Традиція Hello, World!

Знайомство з новою мовою програмування часто починають із виведення привітання. У Python для цього є команда print().

print("Hello, World!")

Але не обов’язково вітатися англійською. Напиши власне привітання українською або будь-якою іншою мовою.

print("Привіт, світе!")
Як працює команда?

print — назва команди; круглі дужки містять те, що потрібно вивести; лапки позначають початок і кінець тексту. Самі лапки у результаті не з’являються. Кожна нова команда print() за замовчуванням виводить текст з нового рядка.

Створи екран запуску своєї гри

Натисніть «Запустити код». Прочитайте повідомлення на екрані. Потім виконайте три завдання:

  1. Придумайте власну назву гри.
  2. Напишіть у привітанні своє ім’я безпосередньо в коді замість імені Максим.
  3. Придумайте власну фразу, з якої починатиметься гра.
Знову запустіть код і подивіться на стартовий екран.
