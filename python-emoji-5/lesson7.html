Термометр дракона

Числова пряма й порівняння чисел

🌡️

🔎 Відкриття дня

Температура може бути вище й нижче нуля. −5 °C холодніше, ніж −2 °C, бо −5 розташоване лівіше на числовій прямій. Python порівнює числа знаками >, < та ==.

Знак > означає «більше», < — «менше», == — «дорівнює». Це порівняння, а не присвоєння значення.

📚 Чому −8 холодніше, ніж −3?

Термометр — приклад числової прямої. Чим лівіше число, тим воно менше. Для погоди важливо не лише число, а й його знак. У Python знаки <, > та == допомагають порівнювати значення.

💻 Досліди код

Прочитай приклад, натисни «Запустити», а потім зміни один рядок. Якщо бачиш нову команду — знайди її пояснення вище.

🤖 ШІ — помічник, а не автор

Якщо код не працює, спочатку прочитай помилку. Потім можна попросити ШІ пояснити її простими словами, але не писати всю програму замість тебе.

«Я вивчаю Python. Поясни, що означає моя помилка, і дай одну підказку, не розв’язуючи завдання за мене. Ось код: …»

Не вводь у ШІ особисті дані, паролі й адреси.
