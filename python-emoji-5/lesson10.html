🌍 Дізнайся щось нове

Однакові наліпки й квитки виготовляють за шаблоном. Цикл у програмі — теж спосіб повторювати дії.

Цікаво знати

range(5) задає п’ять кроків із номерами від 0 до 4.

💡 Дізнатися більше

range(5) дає числа 0, 1, 2, 3, 4. Лічильник i + 1 дозволяє нумерувати квитки від одиниці.

🐍 А як це працює у Python?

for повторює команди з відступом. Для звичної нумерації друкуй i + 1.
