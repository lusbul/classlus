Світлофор рішень

Кілька варіантів: elif

🚥

🔎 Відкриття дня

Іноді є не два, а три чи більше варіантів. Конструкція if / elif / else перевіряє умови по черзі та обирає першу відповідну гілку.

Якщо score >= 8, отримаємо золоту відзнаку; інакше перевіримо score >= 5; якщо жодна умова не підходить — спрацює else.

📚 Чому одного if іноді замало?

Настрій може бути не лише веселим чи сумним: буває спокійний, енергійний, задумливий. Коли варіантів більше двох, зручно використовувати elif. Програма перевіряє умови по черзі.

💻 Досліди код

Прочитай приклад, натисни «Запустити», а потім зміни один рядок. Якщо бачиш нову команду — знайди її пояснення вище.

🎨 Творча лабораторія

Створи три рівні настрою персонажа залежно від кількості зірок.

🌍 Місія з реального життя

Створи «смайлик настрою» з трьома варіантами: 1 — 😄 радісний, 2 — 😌 спокійний, 3 — 🤔 задумливий. Програма має показувати відповідний смайлик, а для інших чисел — ввічливе прохання повторити вибір.

Три рішення

Встанови кількість зірок і знайди відповідну відзнаку.

🧩 Перевір себе

Для чого потрібен elif?

🤖 ШІ — помічник, а не автор

Якщо код не працює, спочатку прочитай помилку. Потім можна попросити ШІ пояснити її простими словами, але не писати всю програму замість тебе.

«Я вивчаю Python. Поясни, що означає моя помилка, і дай одну підказку, не розв’язуючи завдання за мене. Ось код: …»

Не вводь у ШІ особисті дані, паролі й адреси.
