Цифрова майстерня · ClassLus

1. Завантажте папку math-art у корінь репозиторію ClassLus.
2. Сторінка курсу: math-art/index.html
3. Додайте в розділ програмування посилання math-art/index.html із назвою «Цифрова майстерня: Turtle + Math + Art».

Папка містить 6 тем, вихідні PDF, Python-приклади, локальні бібліотеки запуску, завдання, самоперевірку й текстовий звіт.
Запускайте через GitHub Pages або локальний вебсервер. Прогрес зберігається в браузері. Звіт треба передати вчителю самостійно.
Оригінальні презентації збережено без редагування; уточнені пояснення розміщено на сторінках тем.
