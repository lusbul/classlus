ОНОВЛЕННЯ CLASSLUS: КУРС PY GAME ZERO

Що містить архів:
- programming.html — сторінка «Програмування» з карткою нового курсу;
- pygamezero-course/ — головна сторінка курсу, 10 уроків, стилі, інтерактиви та 10 окремих ілюстрацій.

Як додати на GitHub Pages:
1. Розпакуйте архів у кореневу папку репозиторію classlus.
2. Погодьте заміну programming.html.
3. Завантажте папку pygamezero-course повністю, не змінюючи структуру файлів.
4. Дочекайтеся оновлення GitHub Pages.

У курсі є прямі переходи до ePython (https://samel.ho.ua/) і PGZ Studio (https://ed-info.github.io/pgz/). Код копіюється кнопкою. Вправа на впорядкування працює перетягуванням і кнопкою зі стрілками.
