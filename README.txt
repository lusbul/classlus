ClassLus — «Кібербезпека та криптографія. Перші кроки»

Завантажте workshops.html та всю папку first-steps у корінь репозиторію classlus.
УВАГА: workshops.html побудовано на попередньому макеті, не на вихідному файлі живого сайту. Збережіть поточний файл перед заміною. Якщо чинне оформлення важливе, скопіюйте лише посилання на нову майстерку у ваш оригінальний workshops.html.

Вісім уроків: сюжетні ілюстрації, короткі теоретичні блоки, лабораторії, локальний прогрес, PDF через друк браузера, два сертифікати.
Сертифікати не мають серверної перевірки; працюють лише в тому самому браузері.
Для PDF виберіть «Зберегти як PDF» у вікні друку.
Зображення є фрагментами спеціально згенерованої ілюстрації. Історичні об’єкти в них — художні реконструкції.
