Оновлення STEM Online для ClassLus

Завантажте файли з архіву в корінь репозиторію classlus:
- stem.html — замініть наявний індекс STEM;
- static-electricity.html — нова детективна STEM-майстерка;
- stem-color.html і stem-roof.html — наявні сторінки STEM-майстерок/уроку;
- зображення з папки stem-assets — додайте в наявну папку stem-assets.

Не завантажуйте ZIP як єдиний файл: спершу розпакуйте архів. Не видаляйте інші зображення з stem-assets.

У майстерці «Справа № 07: плівка, що не відпускає» є симуляція PhET, домашній дослід зі статичною електрикою, таблиця для вимірювань, drag & drop для сортування доказів і ТРВЗ-виклик.
