ВІДНОВЛЕННЯ ГОЛОВНОЇ CLASSLUS

Це index.html з учорашньої версії сайту. Архів містить лише головну сторінку.

Як опублікувати:
1. Розпакуйте архів.
2. Завантажте index.html у корінь репозиторію classlus і замініть поточний index.html.
3. Не замінюйте style.css та папку assets. Потрібна графіка assets/classlus-design.png уже лежить у репозиторії.
4. Натисніть Commit changes і дочекайтеся оновлення GitHub Pages.

Головна сторінка зафіксована в цьому вигляді. Подальші архіви курсів не повинні містити index.html.
