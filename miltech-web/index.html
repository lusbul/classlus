ПРОДУКТ 03 · Машинне навчання

PyTorch

Навчальна модель оцінки потреби в запасах гуманітарної допомоги

Відкрити Google Colab ↗
import torch
torch.manual_seed(4)
x=torch.tensor([[1.],[2.],[3.],[4.],[5.]])
y=2*x+1
model=torch.nn.Linear(1,1)
opt=torch.optim.SGD(model.parameters(),lr=0.01)
for epoch in range(500):
    opt.zero_grad()
    loss=((model(x)-y)**2).mean()
    loss.backward();opt.step()
print("Прогноз для 6 умовних пунктів:",model(torch.tensor([[6.]])).item())
Що перевірити самостійно?

Змініть залежність y, кількість епох та навчальну швидкість. Поясніть різницю між прогнозом і фактом.

ПРОДУКТ 06 · Імітація процесів

SimPy

Черга на видачу гуманітарних наборів

Відкрити Google Colab ↗
%pip -q install simpy
import simpy
def visitor(env,desk,i):
    arrival=env.now
    with desk.request() as req:
        yield req
        print(f"Відвідувач {i}: очікування {env.now-arrival} хв")
        yield env.timeout(3)
def arrivals(env,desk):
    for i in range(8):
        env.process(visitor(env,desk,i))
        yield env.timeout(2)
env=simpy.Environment()
desk=simpy.Resource(env,capacity=1)
env.process(arrivals(env,desk));env.run()
Що перевірити самостійно?

ПІДСУМКОВИЙ ПРОЄКТ

Цифровий центр допомоги

Створіть у Google Colab невелику систему для планування роботи цивільного пункту допомоги. Вона оцінює кількість відвідувачів, моделює чергу та показує графік навантаження. Розширення: використайте NetworkX для вигаданої мережі пунктів і SciPy для аналізу синтетичних сигналів обладнання.

Відкрити Colab ↗
import numpy as np
import matplotlib.pyplot as plt
hours=np.arange(9,18)
arrivals=np.array([4,7,12,15,13,11,9,6,3])
capacity=10
queue=[]
waiting=0
for count in arrivals:
    waiting=max(0,waiting+count-capacity)
    queue.append(waiting)
fig,ax=plt.subplots(1,2,figsize=(11,4))
ax[0].bar(hours,arrivals,label="Звернення")
ax[0].axhline(capacity,color="red",linestyle="--",label="Пропускна здатність")
ax[0].legend();ax[0].set_title("Навантаження")
ax[1].plot(hours,queue,marker="o")
ax[1].set_title("Орієнтовна черга")
plt.show()
print("Максимальна черга:",max(queue))
