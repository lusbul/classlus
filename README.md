# ClassLus — сайт для GitHub Pages

## Як завантажити
1. Розпакуйте ZIP на комп’ютері.
2. Відкрийте свій репозиторій GitHub → Add file → Upload files.
3. Завантажте ВМІСТ папки ClassLus: index.html, решту HTML, style.css і папку assets. Файл index.html має бути в корені репозиторію.
4. Натисніть Commit changes.
5. Settings → Pages → Deploy from a branch → main → / (root) → Save.

Сайт працює без збірки, встановлення бібліотек і входу в ChatGPT.

## Склад
- index.html — головна за схваленим макетом.
- programming.html — п’ять курсів програмування.
- security.html — CyberLab і криптографія.
- stem.html — STEM-матеріали.
- workshops.html — ТРІЗ та Ейдос.
- live.html — живі уроки.
- style.css — спільний стиль, адаптація для телефона.
- assets/classlus-design.png — схвалена графіка з Бучем.

Головна використовує фрагменти схваленої ілюстрації через CSS, щоб точно зберегти вигляд. Усі чотири плашки й нижній блок є справжніми посиланнями. Назви в зображенні змінюються через оновлення графіки; посилання — в index.html.

В інших розділах назви, описи та посилання — звичайний HTML. Щоб додати курс, скопіюйте блок <a class="course">, змініть номер, назву, опис і href.

Розклад та адресу онлайн-зустрічей додайте в live.html: вони не були надані. Кнопка реєстрації або вигадане посилання не додаються.

## Оновлення: текстові ігри Python
Новий курс розташовано в text-games/. На programming.html додано шостий курс та нову ілюстрацію. Окремого репозиторію не потрібно.
Python запускається через Pyodide 0.27.7 з CDN у Web Worker. Перший запуск потребує інтернету; кнопка зупинки завершує worker. Відповіді для input() вводяться заздалегідь по рядках.
Код та чеклісти зберігаються локально у браузері; оцінки вчителю автоматично не передаються.
