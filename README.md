## Публікація на GitHub Pages
1. Розпакуйте ZIP.
2. Завантажте всі файли й папки з архіву в корінь репозиторію: index.html, hero.png, assets, lesson-01 … lesson-12, README.md та .nojekyll.
3. Збережіть структуру папок. Не завантажуйте сам ZIP замість його вмісту.
4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
5. Дочекайтеся завершення публікації та відкрийте посилання Pages.

Якщо сайт уже існує, замініть головний index.html і додайте всі папки з цього архіву. Сайт не потребує збірки або сервера для Python/JavaScript-практики.

## Що всередині
- Головна з вашим новим зображенням та навігацією на 12 тем.
- Тема 1 збережена й винесена на окрему сторінку.
- Теми 2–12: 73 кроки квестів, 44 підсумкові ситуації, 11 тренажерів, лабораторії трьох мов та мініпроєкти.
- Вправи: вибір рішення, коротка відповідь, перетягування/зіставлення, побудова послідовностей. Перетягування також доступне через кнопки.
- Python і JavaScript: редагування, запуск, зупинка, відкриті тести, завантаження коду.
- C++: копіювання коду й перехід у Programiz; перевірка за таблицею тестів вручну.
- Теми 2–12: завантаження текстового звіту та локальне збереження коду, кроку, плану й результатів.

## Обмеження
Python потребує інтернету для Pyodide (jsDelivr) під час першого запуску сторінки. GUI/Turtle в консольному раннері не працюють. Запуск має ліміти часу та обсягу виведення. JavaScript print/readline/prompt надаються навчальним раннером; це не твердження про стандартні глобальні функції будь-якого JS-середовища. C++ виконується в зовнішньому сервісі.

Тестові набори відкриті й призначені для навчання. Успішні тести не доводять правильність для всіх даних. Дані не надсилаються вчителю автоматично: учень завантажує звіт і передає його окремо. Результати зберігаються лише на поточному пристрої/браузері. Після зміни коду попередній результат лабораторії вважається неактуальним.

Прототип бота й симулятор Git є локальними моделями; вони не створюють справжнього Telegram-бота, репозиторію або комітів. Реальні токени, паролі та секрети не потрібні.

## Методичне поглиблення
Матеріали адаптовано з наданих PDF 2(4), 3, 4, 5(1), 6, 7, 8, 9, 10, 11, 12. Уточнено типізацію та виведення типів, константи й змінюваність, відмінності ділення, межі умов, інваріанти циклів, return і print, передачу аргументів, Unicode, колізії хешування, допоміжну пам’ять, Big O, ітерації розробки й staging у Git.

Додано контрактні задачі, граничні тести, дослідження поведінки, обґрунтування вибору та самостійні мініпроєкти. PDF не копіюються на сайт; зовнішні посилання на оригінальний курс не додано.

## Перевірка
Приклади тем 2–12 пройшли 37 тестових випадків кожною мовою: Python, JavaScript та C++17. У браузері перевірено повний квест теми 2, усі типи вправ, Python/JavaScript-автоперевірку, сторінки поглиблення 2–12, Unicode, Git, прототип бота та підсумкову перевірку теми 11. Відносні посилання перевірені.
