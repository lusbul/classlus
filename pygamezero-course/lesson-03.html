Оживляємо фігури: анімація

Досліджуємо, як draw() показує кадр, а update() змінює дані для наступного. Рух виникає зі зміни координат.

Відкрити ePython ↗Відкрити PGZ Studio ↗

🎯 Що навчимося робити

Розрізняти функції draw() і update() та створити простий рух.

Працюємо крок за кроком

  1. Запустіть програму й простежте шлях кульки.
  2. Знайдіть у update() рядок, який змінює координату x.
  3. Змініть швидкість dx і порівняйте рух.
  4. Додайте повернення кульки до лівого краю, коли вона виходить за правий.
Як перейти від сторінки до запуску коду
  1. Натисніть «Копіювати код» і скопіюйте приклад.
  2. Відкрийте ePython, вставте код у редактор і натисніть «Виконати».
  3. Для графічного вікна PyGame Zero та імпорту PNG відкрийте PGZ Studio. У ній є кнопки «Виконати» й «Імпорт ресурсів».
Код зберігається у браузері; за потреби скористайтеся кнопкою збереження у самому середовищі.

⌨️ Код для дослідження

Скопіюйте код, відкрийте середовище та змініть хоча б одне значення. Порівняйте результат.

Python · PyGame Zero
import pgzrun
WIDTH = 600
HEIGHT = 350
x = 40
y = 170
dx = 3

def update():
    global x
    x += dx
    if x > WIDTH + 20:
        x = -20

def draw():
    screen.fill((25, 35, 60))
    screen.draw.filled_circle((x, y), 24, (255, 190, 70))
    screen.draw.text("update() змінює координати", (20, 20), color="white", fontsize=24)

pgzrun.go()

Завдання

Що станеться, якщо замінити x += dx на x -= dx?

Анімація — це багато кадрів поспіль, а між ними змінюються дані.

Кулька рухатиметься ліворуч, бо координата x зменшуватиметься на кожному оновленні.
