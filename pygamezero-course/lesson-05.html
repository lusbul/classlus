Клавіатура керує героєм

Перевіряємо натиснуті клавіші в update() і змінюємо координати персонажа. Додаємо межі ігрового світу.

🎯 Що навчимося робити

Налаштувати керування стрілками та не дозволити герою зникнути за краєм екрана.

Працюємо крок за кроком

  1. Запустіть приклад і керуйте круглим героєм клавішами зі стрілками.
  2. Знайдіть, як натискання ліворуч змінює x.
  3. Змініть speed і порівняйте швидкість руху.
  4. Додайте перевірки меж, щоб герой залишався всередині екрана.
Як перейти від сторінки до запуску коду
  1. Натисніть «Копіювати код» і скопіюйте приклад.
  2. Відкрийте ePython, вставте код у редактор і натисніть «Виконати».
  3. Для графічного вікна PyGame Zero та імпорту PNG відкрийте PGZ Studio. У ній є кнопки «Виконати» й «Імпорт ресурсів».
Код зберігається у браузері; за потреби скористайтеся кнопкою збереження у самому середовищі.

⌨️ Код для дослідження

Скопіюйте код, відкрийте середовище та змініть хоча б одне значення. Порівняйте результат.

Python · PyGame Zero
import pgzrun
WIDTH = 500
HEIGHT = 400
x = WIDTH // 2
y = HEIGHT // 2
speed = 4

def update():
    global x, y
    if keyboard.left: x -= speed
    if keyboard.right: x += speed
    if keyboard.up: y -= speed
    if keyboard.down: y += speed
    x = max(20, min(WIDTH - 20, x))
    y = max(20, min(HEIGHT - 20, y))

def draw():
    screen.fill((235, 245, 255))
    screen.draw.filled_circle((x, y), 20, (70, 145, 230))

pgzrun.go()

Завдання

У героя рух угору і вниз переплутаний. Які рядки треба поміняти?

Клавіша викликає зміну координати, а межі не дають їй вийти за дозволений діапазон.

Для руху вгору y зменшується, а для руху вниз y збільшується: keyboard.up → y -= speed; keyboard.down → y += speed.
