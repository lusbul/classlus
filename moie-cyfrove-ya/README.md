# Моє цифрове Я · Майстерка для 7–9 класів

## Публікація на GitHub Pages

1. Розпакуйте архів.
2. Завантажте `index.html`, `style.css`, `app.js` в одну папку репозиторію (наприклад, `digital-self/`).
3. Відкрийте `https://ВАШ_ЛОГІН.github.io/ВАШ_РЕПОЗИТОРІЙ/digital-self/` після публікації GitHub Pages.

## Особливості

- 5 послідовних місій; перехід після перевірки результатів.
- Drag-and-drop алгоритму; альтернативне керування натисканням для смартфонів.
- Самооцінка до і після кожної місії, відкриті пояснення, аналіз даних, ситуації цифрової безпеки.
- Підсумковий звіт з усіма відповідями. Кнопка PDF відкриває системний діалог друку: оберіть «Зберегти як PDF».
- Без сторонніх бібліотек, реєстрації, мережевих запитів. Працює офлайн після збереження файлів.
- Прогрес зберігається у localStorage поточного браузера; очищення даних браузера видалить прогрес.
- Усе введене учнем залишається на його пристрої. Учням рекомендовано не вводити конфіденційних даних.

## Перевірка

Відкрийте `index.html` у браузері. Для тестування всіх місій використовуйте кнопку «Почати заново».
